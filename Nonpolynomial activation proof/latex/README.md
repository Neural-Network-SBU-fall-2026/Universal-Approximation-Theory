# اثبات تقریب همگانی؛ متن اصلی و پیوست‌های آموزشی

## نسخهٔ کوتاه برای امتحان

**[سورس مستقلِ نسخهٔ دوصفحه‌ای](uat-exam-short.tex)**

برای نوشتن در امتحان، از این نسخه استفاده کنید: صورت قضیه، پنج گامِ جهت کافی و یک بند برای جهت لازم دارد. توضیحات آموزشی و پیوست‌ها به آن ضمیمه نشده‌اند؛ نسخهٔ کاملِ زیر بدون تغییر برای مطالعه باقی مانده است.

صورت قضیه ضعیف نشده است: فعال‌سازی همچنان پیوسته و غیرچندجمله‌ای است؛ حالت چندمتغیره و یکنواخت‌بودن حدها نیز حفظ شده‌اند. **وایرشتراسِ چندمتغیره / استون–وایرشتراس در نسخهٔ امتحانی قضیه‌ای شناخته‌شده فرض می‌شود**؛ اثبات آن در پیوست‌های نسخهٔ کامل آمده است. تعداد صفحات دست‌نویس به اندازهٔ خط و فاصله‌گذاری بستگی دارد.

فایل `uat-exam-short.tex` مستقل است و نیازی به فایل پیوست ندارد. با تنظیم فونت‌های همین پوشه و دو بار اجرای دستور زیر کامپایل می‌شود:

```bash
xelatex -interaction=nonstopmode -halt-on-error uat-exam-short.tex
```

خروجی بررسی‌شده با فونت نازنین دو صفحهٔ A4 است؛ فونت‌ها در مخزن قرار نمی‌گیرند.

نسخهٔ بازنویسی‌شده، صورت قضیه را در ابتدای سند قرار می‌دهد و اثبات اصلی را بدون فاصله‌انداختنِ لم‌های مقدماتی دنبال می‌کند. عبارت‌های «شروع اثبات» و «پایان اثبات قضیهٔ اصلی» مرز استدلال را مشخص می‌کنند. برای جزئیات ابزارها، ارجاع‌های قابل کلیک به پیوست‌ها و لینک بازگشت به گام مربوط وجود دارد.

## ترتیب خواندن PDF

در نسخهٔ بررسی‌شده با فونت نازنین، سند **۱۶ صفحه** دارد:

| صفحه | محتوا |
| --- | --- |
| ۱ | راهنمای خواندن، صورت دقیق قضیه و ایدهٔ کلی |
| ۲–۳ | گام‌های ۱ تا ۴: توابع قابل تقریب، هموارسازی، مشتق ناصفر و تک‌جمله‌ای‌ها |
| ۴ | گام ۵، جهت لازم و نشانِ پایان اثبات اصلی |
| ۵–۱۵ | هشت پیوست؛ صورت، توضیح و برهان ابزارهای مرتبط |
| ۱۶ | منابع، حدود نتیجه و توضیح تفاوت بازنویسی با متن مقاله |

برای بار اول، صفحات ۱ تا ۴ را پیوسته بخوانید. هنگام نیاز به دلیل یک گام، به پیوستِ ارجاع‌داده‌شده بروید. شمارهٔ صفحات و ارجاع‌ها هنگام کامپایل محاسبه می‌شوند؛ با تغییر فونت ممکن است صفحه‌بندی تغییر کند.

## پیوست‌ها

| پیوست | موضوع |
| --- | --- |
| الف | همگرایی یکنواخت، توابع قابل تقریب و دو قاعدهٔ ترکیب و حدگیری |
| ب | هاینه–بورل، بیشینه و کمینه، هاینه–کانتور و نقش فشردگی |
| پ | قضیهٔ اساسی حساب، قاعدهٔ زنجیره‌ای، مقدار میانگین و مشتق صفر |
| ت | درون‌یابی لاگرانژ و حفظ سقف ثابتِ درجه در حدگیری |
| ث | میانگین‌گیری تکراری، مجموع‌های ریمان یکنواخت و حفظ فعال‌سازی اصلی |
| ج | توجیه دقیق مشتق‌های نسبت به وزن و گام چندمتغیره |
| چ | اثبات وایرشتراس با چندجمله‌ای‌های برنشتاین |
| ح | صورت و اثبات استون–وایرشتراس و کاربرد آن روی فشردهٔ چندمتغیره |

برهان وایرشتراس و استون–وایرشتراس داخل همین سند آمده و از نتیجهٔ شبکه‌ها استفاده نمی‌کند. صورت هاینه–بورل به‌عنوان نتیجهٔ کلاسیک پذیرفته می‌شود؛ حد، مشتق، انتگرال ریمان، کامل‌بودن اعداد حقیقی و جبر مقدماتی پیش‌نیازند. بقیهٔ فایل‌های آموزشی پیشین مجموعه تغییر نکرده‌اند.

## ساخت PDF

**هر دو فایل `.tex` را کنار هم نگه دارید.** فایل اصلی `uat-professor-proof.tex` است و پیوست را با دستور `input` می‌خواند. پیوست به‌تنهایی کامپایل نمی‌شود.

از داخل همین پوشه، سه بار XeLaTeX را اجرا کنید:

```bash
xelatex -interaction=nonstopmode -halt-on-error uat-professor-proof.tex
xelatex -interaction=nonstopmode -halt-on-error uat-professor-proof.tex
xelatex -interaction=nonstopmode -halt-on-error uat-professor-proof.tex
```

اجرای مجدد، شمارهٔ صفحات، مراجع و لینک‌های داخلی را نهایی می‌کند. BibTeX لازم نیست. در Overleaf نیز فایل اصلی را همین فایل و Compiler را XeLaTeX قرار دهید. بسته‌های اصلی شامل `xepersian`، `amsmath`، `tcolorbox` و `hyperref` هستند. از pdfLaTeX استفاده نکنید.

## فونت

سورس نخست فونت‌های محلی زیر را جست‌وجو می‌کند:

```text
fonts/IRNazanin-Regular.ttf
fonts/IRNazanin-Bold.ttf
fonts/IRNazanin-Italic.ttf
```

نسخه‌های در اختیار خودتان را می‌توانید با این نام‌ها قرار دهید. در نبود فایل‌های محلی، فونت نصب‌شدهٔ `IRNazanin` و سپس `Amiri` انتخاب می‌شود. متن لاتین با Latin Modern تنظیم می‌شود. فایل‌های فونت در مخزن یا بستهٔ قابل دریافت قرار ندارند؛ تنظیمات پیشین `.gitignore` حفظ شده است.

## مرجع و محدودهٔ ادعا

صورت اثبات‌شده: **فعال‌سازی پیوسته و غیرچندجمله‌ای، یک لایهٔ پنهان، بایاس آزاد، خروجی خطی و عرض متناهیِ قابل افزایش**. هر دو جهت لازم و کافی آمده‌اند؛ شرط «هر تابع غیرخطی» جایگزین شرط دقیق نمی‌شود. همگراییِ تفاضل‌ها و مجموع‌های ریمان یکنواخت است و گام چندمتغیره حذف نشده است.

منبع اصلی: Leshno, Lin, Pinkus & Schocken (1993)، *Neural Networks*، 6(6)، 861–867؛ قضیهٔ ۱ و بخش ۶. [DOI](https://doi.org/10.1016/S0893-6080(05)80131-5) · [PDF نویسنده](https://pinkus.net.technion.ac.il/files/2021/02/neural.pdf).

منبع توضیح مسیر: Pinkus (1999)، *Acta Numerica*، 8، 143–195؛ قضیهٔ ۳٫۱ و گزاره‌های ۳٫۴ و ۳٫۷. [DOI](https://doi.org/10.1017/S0962492900002919) · [PDF نویسنده](https://pinkus.net.technion.ac.il/files/2021/02/acta.pdf).

میانگین‌گیری تکراری، استدلال لاگرانژ و نوشتن مستقیم مشتق‌های چندمتغیره، جزئیات این بازنویسی‌اند. این سند ترجمهٔ لفظ‌به‌لفظ مقاله یا ادعای نتیجه‌ای تازه نیست؛ ساده‌سازی بیان، جایگزین دلیل ریاضی نشده است.
